# Streamer audio

Place your own licensed MP3/WAV/OGG effects here. Configure paths such as
`/audio/my-siuuu.wav` in Control > Audio files / sound check.
Use ASCII letters, digits, underscores and hyphens in names. Subfolders work.
Each effect must be <= 4 MB, <= 8 seconds, mono or stereo.

No music or voice recordings are bundled. Missing, invalid or loading files
fall back to synthesized Web Audio tones. Local sound check requires its own
gesture and plays at 60%; it does not change Overlay mute/volume.
